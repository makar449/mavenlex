# Release Checklist

Use this checklist before sending the project to a client.

## Structure

- [ ] `package.json` is in the root folder.
- [ ] `.env.example` is in the root folder.
- [ ] `README.md` is in the root folder.
- [ ] `test-contracts/test_contract.txt` exists.
- [ ] No `node_modules` folder is included in the ZIP.
- [ ] No real `.env` file or API key is included.

## Commands

- [ ] `npm install` completes.
- [ ] `npm run doctor` passes.
- [ ] `npm run build` passes.
- [ ] `npm run dev` starts frontend and backend.
- [ ] `/api/health` opens in the browser.

## Product preview

- [ ] Home page opens.
- [ ] Analyze page accepts the test contract.
- [ ] Report output appears.
- [ ] Builder page can generate a draft.
- [ ] Export flow is product previewnstrable.
- [ ] Mobile layout is acceptable for product preview.

## Legal-safe wording

Avoid these claims:

- “replaces a lawyer”
- “AI lawyer”
- “guaranteed compliance”
- “final legal advice”

Use this positioning:

> MavenLex helps identify potential risks, explain complex clauses in plain language, prepare questions for a licensed lawyer and generate draft templates for review.

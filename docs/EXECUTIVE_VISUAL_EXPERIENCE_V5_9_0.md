# MavenLex v5.9.0 — Executive Visual Experience

This release focuses on visual quality and user perception. It does not change the core product logic.

## What changed

- Reduced the top navigation to the most important actions.
- Moved secondary pages into the More menu.
- Strengthened the home hero copy and positioning.
- Rewrote the MavenLex question block in a clearer client-facing tone.
- Enlarged cards, cells, forms, and risk blocks to prevent text overflow.
- Improved report KPIs and decision sections for a more executive legal memo feel.
- Polished the dark navy theme with better contrast, gold accents, and calmer surfaces.
- Added a quality check: `npm run executive-visual-check`.

## Intended user perception

MavenLex should feel less like a technical prototype and more like a premium legal AI product: focused, confident, calm, and easier to navigate.

# Client Product walkthrough Script

## 1. Opening

“This is an AI-powered contract assistant. It helps users understand risks before signing, prepare questions for a licensed lawyer, and generate draft contract templates for review.”

## 2. Analyze flow

1. Open the Analyze page.
2. Upload `your contract file`.
3. Run analysis.
4. Explain the staged progress: file validation, text extraction, risk detection, report creation.

## 3. Report flow

Show:

- Overall risk score
- Signature readiness recommendation
- High-risk clauses
- Plain-language explanations
- Worst-case scenarios
- Action plan
- Questions for lawyer
- Suggested safer wording
- Export report

## 4. Builder flow

1. Open Builder.
2. Select contract type and jurisdiction.
3. Fill the questionnaire.
4. Generate draft.
5. Show instructions for filling and lawyer review reminders.

## 5. Safety wording

Always say:

“This is informational AI support, not legal advice. Final decisions should be checked by a licensed lawyer.”

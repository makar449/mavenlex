# MavenLex v6.0.0 — Human Legal Counsel AI

This release changes MavenLex from a template-style legal assistant into a more natural Human Legal Counsel AI experience.

## Key changes
- Stronger YandexGPT prompt for human, direct legal reasoning.
- Better handling of messy user language, typos, slang and short questions.
- Chat memory for report and article follow-up questions.
- Weak/refusal answer detection with a second rescue prompt.
- Local fallback now gives practical, human next steps instead of a generic answer.
- Situation Navigator now asks for a human legal-counsel style answer.

## Safety positioning
MavenLex should answer ordinary legal questions directly and usefully, but it must not claim to be a licensed lawyer or help with illegal evasion, evidence destruction, intimidation, forgery or committing crimes.

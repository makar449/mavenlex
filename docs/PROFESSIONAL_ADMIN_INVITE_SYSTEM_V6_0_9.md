# MavenLex v6.0.9 — Professional Admin + Invite System

This release turns the admin area into a cleaner product-control center instead of one long technical page.

## Included
- Professional admin sections: overview, site, roles, security, AI, audit history.
- Invite / role assignment by email.
- Role preview before assigning access.
- Owner-only protection for role and design changes.
- Confirmation before granting admin/owner roles.
- Protection against removing the last active owner.
- Optional per-user limits for AI, contract reviews and allowed tools.
- AI health panel that clearly says whether Live AI is working.
- Audit timeline for admin changes.
- Cleaner account area for normal users.
- Stronger wrapping and card layout so long email/text does not break frames.

## Render
Use:
- Build Command: `npm install`
- Start Command: `node server.js`
- Root Directory: empty

Live AI must be configured with YandexGPT keys. MavenLex does not use template legal fallbacks.

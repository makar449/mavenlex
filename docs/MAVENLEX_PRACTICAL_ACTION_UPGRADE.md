# MavenLex Practical Action Upgrade

This release focuses on practical user help, not extra visual effects.

Added report-level practical outputs:
- Today plan
- What not to do
- If already signed
- Lawyer package
- Ready messages to counterparty
- Clarifying questions
- Money exposure explanation
- Role-based recommendations for customer/provider

AI behavior is now more action-oriented: it should help the user decide what to do next, what to avoid, what to send to a lawyer, and how to communicate with the other side.

Legal safety: MavenLex remains informational and does not replace a licensed lawyer.

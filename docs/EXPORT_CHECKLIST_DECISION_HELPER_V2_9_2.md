# v2.9.2 — Export + Checklist + Decision Helper

This patch improves the main post-analysis workflow.

## Added

- Report export as Markdown and TXT.
- Existing PDF/HTML export remains available.
- Copy short summary for quick sharing.
- Copy key risks for a counterparty or lawyer.
- Copy pre-signing checklist.
- Copy lawyer/counterparty questions.
- Decision Helper block: direct recommendation based on risk score and High/Medium risk count.
- Pre-signing checklist block in the report.
- Account history actions for saved reports: open, download, copy, delete.

## Why

The user should be able to complete the full workflow:

1. Upload contract.
2. Get analysis.
3. Understand whether to sign, negotiate, or show a lawyer.
4. Export or copy the result.
5. Return later from Account history.

## Not included

- Public share links.
- Email sending.
- Styled PDF generator beyond browser print.
- Team collaboration.

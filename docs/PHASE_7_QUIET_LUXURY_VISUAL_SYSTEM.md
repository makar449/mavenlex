# Phase 7 - Quiet Luxury Visual System

This pass does not add product features. It upgrades the visual language of the existing MavenLex into a calmer premium legal-tech style.

## Design direction

- Ivory / champagne / graphite palette
- Thin premium borders instead of heavy neon effects
- Softer private-banking style surfaces
- Calm reveal animations
- Premium hover states
- Better visual hierarchy for Home, Analyze, Report and Builder
- More serious legal-tech feeling, less generic AI-SaaS look

## What changed

- Global color tokens and page background were redesigned.
- Navigation became a floating premium capsule.
- Cards, panels, report blocks and contract paper received unified borders and shadows.
- Buttons were redesigned into subtle graphite/champagne controls.
- Risk badges, report score, upload panel and builder progress now match the same system.
- Motion was added carefully and respects `prefers-reduced-motion`.

## Scope

No backend logic, AI logic, routes, parsing, exports or product features were changed.

# MavenLex v5.8.0 — Premium UI Polish

This release focuses on visual quality after local launch testing.

## Improved

- Main header is simplified: primary navigation now shows only the core user flow.
- Secondary pages moved into the “More” menu to reduce visual noise.
- Cards, form cells and tab content have larger minimum sizes to prevent text clipping.
- FAQ copy was rewritten to sound clearer and more premium for real users.
- Added a saved Premium Dark Navy theme toggle.
- Settings page now includes a color theme selector.
- Added extra wrapping rules for long Russian text, cards, chips and form controls.

## Main user-facing impact

The product now feels less overloaded, easier to understand and more visually premium while preserving the existing MavenLex logic and routes.

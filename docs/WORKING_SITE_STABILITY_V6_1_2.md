# MavenLex v6.1.2 — Working Site Stability

Цель релиза: убрать декоративность и сделать поведение сайта стабильнее.

Что изменено:
- главная страница стала короче;
- декоративные preview-кнопки больше не выглядят как рабочие действия;
- пресеты бренда дают мгновенную визуальную реакцию;
- добавлены toast-сообщения для ключевых админ-действий;
- исправлены переносы текста/email/статусов в кабинете и админке;
- усилена сетка пользователей и назначения ролей;
- статус пользователей на сервере принимает active/suspended/blocked/invited безопасно;
- версия сервера обновлена до 6.1.2.

Не добавлялись новые шаблонные AI-ответы. Если Live AI не подключён, AI-функции должны честно возвращать ошибку.

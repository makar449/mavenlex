# MavenLex v5.9.3 — Navy Full-Screen Polish

Focus: make the dark navy mode feel like a complete full-screen premium theme, not a dark card sitting on a light page.

## Improved
- Full viewport navy background for `html`, `body`, and `#root`.
- Removed light ivory edges in navy mode.
- Added softer light-blue text palette instead of pure white.
- Improved navy card surfaces, fields, dropdowns, menus and FAQ cards.
- Added subtle blue glow and grid texture to make the dark mode feel premium.
- Improved readability for paragraphs, labels, hints, table/cards and disabled controls.
- Kept gold accents only for primary CTAs and active states.

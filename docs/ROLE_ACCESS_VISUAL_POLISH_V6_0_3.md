# MavenLex v6.0.3 — Visual Clarity + Role Access Polish

Focus: improved navy/light readability, shorter hero copy, public cleanup, and admin role-based access management.

## Included
- Better secondary text contrast in navy theme.
- Dark-theme light cards now remain readable.
- Shorter homepage hero: direct value, fewer words.
- Improved large cards in light theme.
- Removed public YooKassa technical checklist from regular user pricing view.
- Smaller FAQ/Questions footer button styling.
- Admin role manager: assign user, analyst, manager, billing, support, admin, owner.
- Navigation and page access respond to the assigned role.
- Render-ready setup: prebuilt `dist`, `.node-version`, and simpler `render.yaml`.

# MavenLex v6.0.6 — Owner Design Studio

Цель версии: сделать админку не быстрым фикс-экраном, а центром управления внешним видом продукта, чтобы владелец мог менять главную страницу, кнопки, рамки, цвета, стиль текста и панели ролей без правки кода.

## Что добавлено

- Owner Design Studio в админке, доступен только роли `owner`.
- Короткий главный экран: “Договор → риски → действия” и короткое описание без длинной идеи сайта.
- Управление цветами: основной текст, акцент, CTA-кнопка, текст кнопки, рамки, светлая карточка, второстепенный текст, navy-фон, navy-карточка, navy-текст.
- Управление UI: тип кнопок, тип рамок, тип текста, compact hero, подчёркивание важных слов.
- Управление выделениями текста по страницам: главная, договор, статьи.
- Редактирование панелей ролей через owner-admin.
- Live AI only: если AI не подключён, продукт честно показывает, что AI не работает. Локальных шаблонов вместо AI нет.

## Проверено

- `npm run build`
- `node --check server.js`
- `npm run deployment-version`
- `/api/health`
- `/api/public/config`

```text
Build Command: npm install

```

```env
DISABLE_LIVE_AI=false
YANDEX_API_KEY=...
YANDEX_PROJECT_ID=...
YANDEX_MODEL=gpt://.../yandexgpt/latest
```
